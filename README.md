# Aulas de Java

Repositório com uma coleção de projetos e exercícios desenvolvidos durante as aulas de Programação Orientada a Objetos, com foco em aprendizado prático de Java.

Este projeto reúne exemplos simples e aplicações de estudo que exploram conceitos como:

- variáveis e tipos de dados
- estruturas condicionais e de repetição
- métodos e funções
- orientação a objetos
- interfaces gráficas com Swing e JavaFX
- manipulação de dados e lógica de programação

## 📚 Estrutura do repositório

Os diretórios representam diversos exercícios e mini-projetos, incluindo:

- `Atividade 1` — atividades introdutórias
- `BancoUAM` — exercícios relacionados a lógica de banco / dados
- `CalculoIMC` — cálculo de índice de massa corporal
- `ConverterHoras` — conversão entre unidades de tempo
- `Diario` — aplicação simples de agenda/diário
- `Equacao2Grau` — resolução de equações do segundo grau
- `ImagemPixels` — manipulação de pixels de imagens
- `Letras` — exercícios com processamento de letras
- `Login` — sistema simples de autenticação
- `MesesDoAno` — listagem e manipulação dos meses do ano
- `Metodos` — prática com métodos
- `OlaMundoJavaFX` — exemplo de Hello World em JavaFX
- `OlaMundoSwing` — exemplo de Hello World em Swing
- `Resistencias` — cálculos com resistências elétricas
- `calculadoraIdade` — cálculo de idade a partir de datas

## 🚀 Como executar

Pré-requisitos:

- Java JDK instalado
- IDE opcional: IntelliJ IDEA, Eclipse ou NetBeans

Para compilar e executar um projeto Java básico:

```bash
javac *.java
java NomeDaClasse
```

Se o projeto estiver em uma pasta específica, navegue até ela antes de compilar.

## 🧠 Objetivo do repositório

O objetivo principal é praticar os fundamentos da linguagem Java e desenvolver a lógica de programação por meio de pequenos exercícios e projetos didáticos.
